# Учебный проект: Vue Router

Тема: небольшой сайт об играх. Цель — увидеть, как адрес выбирает страницу.

## Где находится роутер

1. `src/router/index.js` — список адресов и соответствующих страниц.
2. `src/main.js` — подключение роутера через `.use(router)`.
3. `src/App.vue` — ссылки `<RouterLink>` и место для страницы `<RouterView />`.
4. `src/pages/GamesPage.vue` — ссылка на игру с параметром `id`.
5. `src/pages/GamePage.vue` — получение `id` и показ выбранной игры.

## Проверь сам

| Адрес          | Что увидишь     |
| -------------- | --------------- |
| `/`            | Главная         |
| `/games`       | Список игр      |
| `/games/chess` | Страница шахмат |
| `/about`       | О проекте       |
| `/anything`    | Страница 404    |

## Запуск

Открой эту папку в VS Code, открой терминал и выполни:

```bash
npm install
npm run dev
```

Затем открой адрес, который появится в терминале. Не открывай `index.html` как обычный файл.

## Самостоятельные задания

1. Добавь в меню ссылку на новую страницу «Контакты».
2. Добавь четвёртую игру в `src/data/games.js`.
3. Измени текст страницы 404.
